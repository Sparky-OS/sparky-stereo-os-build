# Sparky Stereo OS: the edition's build tree (local only)

Packages, the repository tools, the kernel, the ISO build, Lean Code, the Secure Boot scripts, translations, gl-stereo, the edition's plans and notes, and the forks it builds from.
Moved here with its history from the SteamVR driver's repository on 2026-10-21; that repository keeps only the SteamVR driver, which is one of this edition's packages.
The old paths in the SteamVR driver's repository are symlinks to this tree, so existing scripts and briefs keep working.
This repository has no remote by Daniel's decision; public parts are published from Sparky-OS/sparky-stereo-os.
