# skills-mcp

The skills server of Sparky Stereo OS, written in cgm-zig: one engine, three doors (command line, MCP over stdio, the person's dialog).
`docs/TREE.md` is the layout and its rules, `docs/CONTRACT.md` the engine's contract, `tests/README.md` what is tested.
Milestone 2a: the tree, the contract and the first failing tests; the code follows in 2b.
