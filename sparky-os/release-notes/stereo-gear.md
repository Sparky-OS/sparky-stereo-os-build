# Stereo gear with more than one 2D frame

Frame-sequential modes are for DLP-Link projectors, CRT shutter-glasses setups, and 120 Hz panels with their own glasses emitter; KScreen lists both left-eye-first and right-eye-first twins under `Other stereo formats`. Pair modes are for polarised dual-projection rigs, mirror rigs, and iZ3D dual-panel monitors; from an output's KScreen page, enable `Other stereo formats`, choose the partner, choose the pair type, and select the eye or iZ3D input and mirror reflection when applicable. The protocol, KWin mock-DRM paths, libkscreen persistence, KScreen controls, and headless tests were verified in containers, but none of these formats has yet been run on a real projector, shutter-glasses emitter, 120 Hz panel, mirror rig, or iZ3D monitor; hardware timing and image quality still need testing with the gear. USB-emitter systems such as NVIDIA 3D Vision remain outside this work.
