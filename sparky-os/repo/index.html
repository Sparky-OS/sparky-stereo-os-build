Sparky Stereo OS repository

The package repository of Sparky Stereo OS 9 "Mashtabba" (based on Debian 14 "Forky"), an edition of SparkyLinux created by Paweł "pavroo" Pijanowski and Daniel Ramos (Capitain Jack).

The edition is built on SparkyLinux testing and needs its repository first: see SparkyLinux's testing repository page.

Then add this one, as root:

wget -O - https://repo.sparkyos.org/sparky-stereo-repo.asc | tee /etc/apt/trusted.gpg.d/sparky-stereo-repo.asc

cat > /etc/apt/sources.list.d/sparky-stereo.sources <<'EOF'
Types: deb
URIs: https://repo.sparkyos.org/
Suites: mashtabba
Components: main
Signed-By: /etc/apt/trusted.gpg.d/sparky-stereo-repo.asc
EOF

cat > /etc/apt/preferences.d/sparky-stereo <<'EOF'
Package: *
Pin: release o=Sparky Stereo OS
Pin-Priority: 1001
EOF

apt-get update

The short way, once that is done, keeps these files up to date through the packages:

apt-get install sparky-stereo-keyring sparky-stereo-apt
