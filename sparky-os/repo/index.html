Sparky Stereo OS repository

The package repository of Sparky Stereo OS 9 "Mashtabba" (based on Debian 14 "Forky"), an edition of SparkyLinux created by Paweł "pavroo" Pijanowski and Daniel Ramos (Capitain Jack).

To add it, run as root:

curl -fsSL https://repo.sparkyos.org/sparky-stereo-archive-keyring.gpg -o /usr/share/keyrings/sparky-stereo-archive-keyring.gpg

printf 'Types: deb\nURIs: https://repo.sparkyos.org/\nSuites: mashtabba\nComponents: main\nSigned-By: /usr/share/keyrings/sparky-stereo-archive-keyring.gpg\n' > /etc/apt/sources.list.d/sparky-stereo.sources

apt-get update
