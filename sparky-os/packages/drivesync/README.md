# DriveSync

Rafael Tosta's Google Drive client ([rafatosta/drivesync](https://github.com/rafatosta/drivesync), GPL-3.0-only, Rust and GTK 4), built from source for the user image (queue row 299).

- `make-orig.sh OUTDIR` (network, cargo): the commit's tree pinned by archive SHA-256, commit and git tree id, and `cargo vendor --locked` of that tree with `debian/patches` applied; writes `crate-licences.tsv`, `crate-licences/` and `cargo-config.toml`.
- `build.sh OUT CLONE [COMMIT]` (`SPARKY_SCRATCH`, `SPARKY_LC_ARCHIVE_DIR`, `REPO`; `ORIG_CACHE` reuses make-orig's output): checks the vendor tree's digest, the licence table and every legal file's hash, then builds through the Lean Code toolkit (`release/build-dh-lean.sh`).
- `debian/patches` are the eight commits of the fork branch `order299` (data directory, system certificate store, tray, notifications, metered connections, Places, ten languages, AppStream licence), exported with `git format-patch` and DEP-3 fields; regenerate them from the branch, never edit them here.
- `debian/copyright` is generated by `debian/gen-copyright.py` from the crate table; the build stops when it differs.

No Google OAuth client is shipped (README.Debian).
The proof without a Google account, against a local stand-in of Google's endpoints, is in the skills repository: `skills/edition-packaging/references/a-gtk-rust-program-at-home-in-kde.md`.
