# Desktop shortcut terminology

The shortcut opens the person’s home folder and uses the classic Windows My Documents name, as directed for ORDER 673 on 18 November 2026.
It retains the user-home icon; it does not target the Documents subfolder.
These are the Windows 2000/XP forms, rather than the shorter Documents label used by later releases.
German deliberately uses the XP-era Eigene Dateien, not later Eigene Dokumente.
Portuguese uses Meus Documentos, matching the recorded decision and Microsoft’s profile-directory table.
The installed catalogue is desktop-shortcuts.json; no label is read from KDE’s catalogues.
