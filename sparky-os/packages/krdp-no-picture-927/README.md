# First picture deadline for a paired Throw

Catch waits 25 seconds after starting the approved RDP session.
Its first decoded image cancels the timer.
On expiry Catch displays the error, stops listening and closes the RDP session without retrying.
Before closing an active, still-paired TLS control connection, Catch sends a final `no-picture` action.

KRdp discovery accepts that action on an approved lease over the existing paired connection.
It shows a desktop notification and lets the lease close.
The action contains no user-supplied text.
The phone and PC catalogues carry the same sentence in the edition's ten languages, including the English source string.

The `next-source.sh` recipe advances the verified KRdp +stereo3d11 and KRDC +stereo3d3+lc1 source closures.
Set `SOURCE` to `krdp` or `krdc`.
