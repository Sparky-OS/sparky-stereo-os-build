command-not-found (23.04.0-3+sparky1) mashtabba; urgency=medium

  * Name the program Debian installs under another name first (Sparky Stereo
    OS, ORDER 252b J15): /usr/share/command-not-found/renamed-commands lists
    the commands Debian renamed because another package has the name (Debian
    Policy 10.1), so `fd` offers fd-find, run as fdfind, before fdclone, and
    `bat` offers bat, run as batcat, before bacula-console-qt. The packages
    that have the command under its own name stay listed after it; a command
    with no row is advised as before.
  * The table is made from Debian forky's Contents, Packages and popularity
    contest and each package's own README.Debian, NEWS or changelog
    (make-renamed.py in the Sparky Stereo OS build tree).
  * The two new messages ship in pl, pt_BR, fr, de, ja, ko, zh_CN and zh_TW,
    translated by Claude for Daniel Ramos (Capitain Jack).
