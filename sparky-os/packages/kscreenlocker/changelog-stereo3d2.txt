kscreenlocker (6.7.4-1+stereo3d2) unstable; urgency=medium

  * greeter: draw the wallpaper below the interface where it shows depth
    (s2-0001, invent danielcamposramos/kscreenlocker
    lock-wallpaper-below-291). On Wayland each screen's lock screen gets a
    child window for its wallpaper, which Qt places below the lock screen
    (Qt::WindowStaysOnBottomHint, qt6-base +stereo3d13), so that Stereo
    KWin draws the wallpaper behind the screen, as the desktop's, and keeps
    the clock, the password field and the rest of the interface at it. The
    wallpaper goes there only while the compositor says the screen shows
    depth (kde_stereo_depth_v1, through libstereo-declare 1.5), the
    Background depth (kwinrc [StereoDepth] SunkLimit) is above zero and the
    stereo show is not on; on a 2D screen and with a Background depth of 0
    the lock screen is drawn exactly as before. A Qt that does not place
    the window below (no _q_wayland_below_parent) keeps the wallpaper in
    the lock screen's window, with a warning.
  * Build-Depends: libstereo-declare-dev (>= 1.5).
