# Debian packages and installed-file proof

Credit: Sparky Stereo OS, Daniel Ramos's edition of SparkyLinux (by Paweł "pavroo" Pijanowski).

This directory contains the source packaging, build bootstrap and installed-file
regression harnesses. Measured results are kept with the test record.
Build trees and dependency environments belong on /mnt/build/gl-stereo.

`Dockerfile.base` selects amd64 explicitly: the shared cached debian:testing
tag was i386. Build it with Docker's configuration directory inside this
workspace, using the lane's Docker proxy. Register the image and each
container in ../.artifacts before creating them. The current lane-owned
base tag is gl-stereo-package-base:1.

Run audit-sources.sh from the repository root inside a fresh non-root base
container, with this workspace mounted read-write and
/var/local/sparky-stereo-repo mounted at the same path read-only. It uses
separate writable APT lists/cache under out/packages/apt, Debian testing
binary/source indexes, the edition's file:/// source, and deb-multimedia's
forky source verified by the carried public keyring. It does not install
packages. It downloads Debian source archives, records candidate dependency
versions, and simulates package build dependencies. Output is out/packages/.
Create apt/lists/partial and apt/cache/archives/partial before running.

check-patches.sh runs inside a non-root container with dpkg-dev and patch.
It extracts the downloaded source archives when absent and checks the three
accepted patches with --dry-run. No Debian rules, control, copyright or
changelog is changed by this check. Sources are downloaded through verified
APT indexes; dpkg-source's separate maintainer-signature check is skipped.

Package versions from the measured testing sources:

- gl-stereo 0.2.0-1 (the existing repository has 0.1.0-1).
- kscreenlocker 6.7.4-1+stereo3d1.
- plasma-desktop 4:6.7.4-1+stereo3d1.
- xscreensaver 6.09+dfsg1-2+stereo3d1, retaining its other hacks and options.

Prepare real 3.0 (quilt) source packages with the edition
Maintainer/Homepage, Debian Original-Maintainer where applicable, and the
credit above. Preserve Debian's existing build/test rules. The gl-stereo
build must use the packaged libstereo-declare-dev >= 1.1.0 and generated
shlibs dependencies, with no helper dependency patch. Qualify the actual
stripped/installed saver binaries and bind receipts to those hashes. Build
and test every installed package, run lintian, and create SHA256SUMS before
handoff, and keep the final verification results with the test record.

The dependency root filesystem and build trees live on /mnt/build/gl-stereo.
bootstrap.sh extracts the digest-pinned amd64 base there and downloads PRoot
from Debian's verified indexes. in-rootfs.sh runs that filesystem inside a
UID 1000 container (four CPUs, seccomp disabled for PRoot tracing), with the
edition repository mounted read-only. install-deps.sh updates testing and
installs dependencies without giving the container host-root privileges.
Current free-space floors: /K3D 5 GB, / 12 GB, /mnt/build 15 GB.

Debian PRoot 5.4.0-3 needs proot-empty-path.patch for systemd 262:
readlinkat(fd, "", ...) must resolve fd before detranslating its result.
The original aborts while configuring systemd; the patched tool completes
`dpkg --configure -a` with status 0. build-proot.sh compiles this bootstrap
tool in the compiler container (gl-stereo-test:3), with four jobs.
The target package environment remains freshly updated Debian testing.

prepare-upstream.py adds the accepted patches to the unmodified testing
source trees under /build/sources. Original-Maintainer is exported into both
source and binary controls using Debian's XSBC prefix. The script refuses
to prepare an already modified changelog. All three quilts applied with
status 0. Build each with build-upstream.sh NAME inside the dependency root.
KScreenLocker needs the newly built libstereoshow-dev package first.

The bootstrap patch also translates fchmodat2 for the amd64/x86 ABI:
current tar uses it while unpacking source archives, which otherwise fails
on symlink permissions. Debian's package build rules are not changed to
work around this environment issue. The subsequent Plasma source-package
step succeeded and reached CMake configuration. dpkg --audit and the
XScreenSaver build-dependency check both returned 0.

The core source package is now implemented in debian/. Its normal build
qualifies the stripped stage after dh_strip. libGL and libEGL need explicit
runtime dependencies because the layer loads them with dlopen; the helper's
>=1.1.0 dependency is generated by dpkg-shlibdeps. The development package
exports only libstereoshow, so KScreenLocker can build without the show app.

The proof starts from another extraction of the same pinned base, updated
with the file repository and the edition's priority-1001 origin pin. That
pin selects the PowerDevil package which provides the edition power policy.
install-proof.sh installs all built binaries plus the rig dependencies.
export-proof.sh prepares this filesystem for a lane-owned Docker image;
regressions run as UID 1000 in fresh containers from that image. Production
paths in test-installed.sh resolve into /usr; only test clients are built.
The Plasma rig uses a read-only oracle catalogue fixture, with hashes from
the installed package, to test deterministic camera depths behind the prompt.
